# lightbox-site-screens (temporary)

Screenshots of the public site https://lightboxcollective.co, every page, each section at rest, at 2× (2880×1800),
captured 2026-10-19 by the `Sitemap` CI job in `michael-roq/lightbox-storybrand` (`scripts/sitemap.mjs`).

This repo is public only so Figma can load the images by URL (`figma.createImageAsync`) onto the Lightbox AI Strategy
Board, page 5 ("LIghtbox Rebrand - Brainstorm"). Michael asked for it to be deleted as soon as the pages are built;
Figma keeps its own copies.

`manifest.json` lists each page's shots in order, with the band of each frame (`keep`, CSS px) that belongs to its
section, so the shots stack into one page without repeating content.
